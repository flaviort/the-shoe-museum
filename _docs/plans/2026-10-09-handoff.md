# Client Handoff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the repo into a Shopify-theme-only project with two safe commands (`npm run dev`, `npm run push`), a CLAUDE.md and a `_docs/` folder, so the store owner can work on it through Claude alongside Flávio.

**Architecture:** The theme moves from `_shopify/` to the repo root and the legacy PHP site is deleted. `npm run dev` and `npm run push` call small Node scripts (`scripts/dev.mjs`, `scripts/push.mjs`) built on four tested helper modules in `scripts/lib/`. Live customizer JSON is always pulled into a temp folder and compared file by file, so the scripts decide what to copy and never let the CLI overwrite or delete local files on its own.

**Tech Stack:** Node 22 (ESM, `node:test`), Shopify CLI 4.x, git, gulp 5, concurrently 9 (already a dependency).

Spec: `_docs/specs/2026-10-09-handoff-design.md`

## Global Constraints

- Store: `the-shoe-museum.myshopify.com`. Live domain: `theshoemuseum.com`.
- Theme targeting always uses `--live`, never a theme name.
- Customizer-owned files: `templates/*.json` and `config/settings_data.json`.
- `npm run dev` never blocks on git state: only a missing Shopify CLI or a failed `npm install` stops it. Everything else is a `[warn]`.
- `npm run push` is strict: every check is an `[ERROR]` that stops before anything reaches live.
- Scripts never prompt for input (Claude runs them non-interactively).
- Output style: one line per check, tagged `[ok]`, `[..]`, `[warn]` or `[ERROR]`.
- No new npm dependencies. No bash wrappers, no `.bat` files. Both users are on macOS.
- All text written (script output, comments, docs, commit messages): no em dashes, no emojis, plain human voice. En dashes only in numeric ranges.
- Never edit compiled assets (`assets/main.min.css`, `assets/main.js`); they are build output.

```js
// Optional .env support. SHOPIFY_CLI_THEME_TOKEN lets someone use a Theme Access
// token instead of the browser login; SHOPIFY_STOREFRONT_PASSWORD gets the local
// preview past a password-protected storefront.

import { existsSync, readFileSync } from 'node:fs'
import { join } from 'node:path'

export const STORE = 'the-shoe-museum.myshopify.com'

export function parseEnv(text) {
    const env = {}
    for (const raw of text.split(/\r?\n/)) {
        const line = raw.trim()
        if (!line || line.startsWith('#')) continue
        const eq = line.indexOf('=')
        if (eq === -1) continue
        let value = line.slice(eq + 1).trim()
        if (/^(['"]).*\1$/.test(value)) value = value.slice(1, -1)
        env[line.slice(0, eq).trim()] = value
    }
    return env
}

export function loadEnv(root) {
    const file = join(root, '.env')
    return existsSync(file) ? parseEnv(readFileSync(file, 'utf8')) : {}
}

export function shopifyArgs(command, env = {}) {
    const args = ['--store', STORE]
    if (env.SHOPIFY_CLI_THEME_TOKEN) args.push('--password', env.SHOPIFY_CLI_THEME_TOKEN)
    if (command === 'dev' && env.SHOPIFY_STOREFRONT_PASSWORD) {
        args.push('--store-password', env.SHOPIFY_STOREFRONT_PASSWORD)
    }
    return args
}
```

```js
// Thin wrapper over spawnSync that never throws: a missing command or a
// timeout comes back as a non-zero code so callers can print a friendly line.

import { spawnSync } from 'node:child_process'

export function run(cmd, args, { cwd, live = false, timeout } = {}) {
    const r = spawnSync(cmd, args, {
        cwd,
        timeout,
        encoding: 'utf8',
        stdio: live ? 'inherit' : 'pipe',
    })
    return {
        code: r.status ?? 1,
        stdout: r.stdout ?? '',
        stderr: (r.stderr ?? '') + (r.error ? r.error.message : ''),
    }
}

export function shellQuote(s) {
    return /^[\w@%+=:,./-]+$/.test(s) ? s : `'${s.replace(/'/g, `'\\''`)}'`
}
```

```js
// Git helpers for dev.mjs and push.mjs. Everything goes through run(), so a
// failure comes back as a result object instead of an exception.

import { run } from './run.mjs'

// Porcelain lines look like "XY path". The first column can be a space, so
// the text must not be trimmed before slicing.
export function parsePorcelain(text) {
    return text
        .split('\n')
        .filter(Boolean)
        .map((line) => {
            const path = line.slice(3)
            const arrow = path.indexOf(' -> ')
            return (arrow === -1 ? path : path.slice(arrow + 4)).replace(/^"|"$/g, '')
        })
}

export function git(root, ...args) {
    return run('git', args, { cwd: root })
}

export function dirtyPaths(root) {
    return parsePorcelain(git(root, 'status', '--porcelain=v1', '--untracked-files=all').stdout)
}

export function countCommits(root, range) {
    const r = git(root, 'rev-list', '--count', range)
    return r.code === 0 ? Number(r.stdout.trim()) : null
}

export function wasDeleted(root, path) {
    return git(root, 'log', '--diff-filter=D', '--format=%h', '-1', '--', path).stdout.trim() !== ''
}

export function commitPaths(root, paths, message) {
    const add = git(root, 'add', '--', ...paths)
    if (add.code !== 0) return add
    return git(root, 'commit', '-q', '-m', message, '--', ...paths)
}
```

- Consumes: `run` from `run.mjs`; `shopifyArgs` from `env.mjs`.
- Produces:
  - `LIVE_JSON: string[]`: `['templates/*.json', 'config/settings_data.json']`
  - `readThemeJson(dir: string): Map<string, string>`: relative path to content for `templates/*.json` (top level only) and `config/settings_data.json` under `dir`.
  - `pullLiveJson(env): { ok: true, files: Map<string,string> } | { ok: false, error: string }`
  - `compareLive({ live, local, dirty, wasDeleted }): { changed: string[], added: string[], deletedLocally: string[], skippedDirty: string[] }` where `live`/`local` are Maps from `readThemeJson`, `dirty` is a `Set<string>` and `wasDeleted` is `(path) => boolean`.
    - `changed`: exists in both, content differs, not dirty locally.
    - `added`: only on live, never deleted in git history (someone created it in the customizer).
    - `deletedLocally`: only on live, deleted in git history (the next push removes it from live).
    - `skippedDirty`: differs from live but has uncommitted local edits.
    - Files only present locally are ignored (push uploads them).
    - Comparison ignores CRLF vs LF and trailing whitespace.
  - `writeLiveFiles(root: string, live: Map<string,string>, paths: string[]): void`

```js
// The customizer saves its content into templates/*.json and
// config/settings_data.json on the live theme. These helpers pull those files
// into a temp folder and compare them with the local copy, so the scripts
// decide what to copy and the CLI never overwrites or deletes local files.

import { existsSync, mkdirSync, mkdtempSync, readdirSync, readFileSync, rmSync, writeFileSync } from 'node:fs'
import { tmpdir } from 'node:os'
import { dirname, join } from 'node:path'
import { run } from './run.mjs'
import { shopifyArgs } from './env.mjs'

export const LIVE_JSON = ['templates/*.json', 'config/settings_data.json']

export function readThemeJson(dir) {
    const files = new Map()
    const templates = join(dir, 'templates')
    if (existsSync(templates)) {
        for (const name of readdirSync(templates)) {
            if (name.endsWith('.json')) files.set(`templates/${name}`, readFileSync(join(templates, name), 'utf8'))
        }
    }
    const settings = join(dir, 'config/settings_data.json')
    if (existsSync(settings)) files.set('config/settings_data.json', readFileSync(settings, 'utf8'))
    return files
}

export function pullLiveJson(env) {
    const dir = mkdtempSync(join(tmpdir(), 'tsm-live-'))
    try {
        const only = LIVE_JSON.flatMap((glob) => ['--only', glob])
        const r = run(
            'shopify',
            ['theme', 'pull', '--live', '--path', dir, ...only, '--no-color', ...shopifyArgs('pull', env)],
            { timeout: 180_000 },
        )
        if (r.code !== 0) {
            const detail = (r.stderr || r.stdout).trim().split('\n').slice(-3).join(' ')
            return { ok: false, error: detail || 'the Shopify CLI did not answer (you may need to log in: run npm run dev in Terminal)' }
        }
        const files = readThemeJson(dir)
        if (files.size === 0) return { ok: false, error: 'the live theme returned no customizer files' }
        return { ok: true, files }
    } finally {
        rmSync(dir, { recursive: true, force: true })
    }
}

const normalize = (s) => s.replace(/\r\n/g, '\n').trimEnd()

export function compareLive({ live, local, dirty, wasDeleted }) {
    const result = { changed: [], added: [], deletedLocally: [], skippedDirty: [] }
    for (const [path, content] of live) {
        if (local.has(path) && normalize(local.get(path)) === normalize(content)) continue
        if (dirty.has(path)) result.skippedDirty.push(path)
        else if (!local.has(path)) (wasDeleted(path) ? result.deletedLocally : result.added).push(path)
        else result.changed.push(path)
    }
    return result
}

export function writeLiveFiles(root, live, paths) {
    for (const path of paths) {
        const file = join(root, path)
        mkdirSync(dirname(file), { recursive: true })
        writeFileSync(file, live.get(path))
    }
}
```

```js
// npm run push: publish to the live theme. Strict on purpose: every check
// stops before anything reaches live. Pass --dry-run to run the checks and
// the build without pushing anything.

import { existsSync } from 'node:fs'
import { dirname, join } from 'node:path'
import { fileURLToPath } from 'node:url'
import { ok, info, warn, fail, title } from './lib/log.mjs'
import { run } from './lib/run.mjs'
import { loadEnv, shopifyArgs } from './lib/env.mjs'
import { git, dirtyPaths, countCommits, wasDeleted, commitPaths } from './lib/git.mjs'
import { pullLiveJson, readThemeJson, compareLive, writeLiveFiles } from './lib/live.mjs'

const root = join(dirname(fileURLToPath(import.meta.url)), '..')
const dryRun = process.argv.includes('--dry-run')
const indent = (paths) => paths.map((p) => `          ${p}`).join('\n')

function stop(msg) {
    fail(msg)
    console.log('\n Nothing was pushed.\n')
    process.exit(1)
}

title(dryRun ? 'The Shoe Museum - push (dry run)' : 'The Shoe Museum - push to live')

// 1. Tools
if (run('shopify', ['version']).code !== 0) stop('Shopify CLI not found. Install it with: npm install -g @shopify/cli@latest')
if (!existsSync(join(root, 'node_modules'))) stop('Dependencies are missing. Run npm run dev once (it installs them), then push again.')
ok('Tools ready')
const env = loadEnv(root)

// 2. Git: clean, and nothing newer on GitHub
const pending = dirtyPaths(root)
if (pending.length) stop(`There are uncommitted changes. Commit or discard them first:\n${indent(pending)}`)
ok('No uncommitted changes')

if (git(root, 'fetch', '-q').code !== 0) stop('Could not reach GitHub to check for newer changes.')
const behind = countCommits(root, 'HEAD..@{u}')
if (behind === null) stop('This branch is not linked to GitHub. Ask for help before pushing.')
if (behind > 0) stop(`GitHub has ${behind} newer commit(s) that are not here yet. Run npm run dev to get them, then push again.`)
ok('Up to date with GitHub')

// 3. Customizer edits made on live since the last sync
info('Checking the live theme for customizer changes...')
const live = pullLiveJson(env)
if (!live.ok) stop(`Could not read the live theme: ${live.error}`)
const diff = compareLive({
    live: live.files,
    local: readThemeJson(root),
    dirty: new Set(),
    wasDeleted: (path) => wasDeleted(root, path),
})
const incoming = [...diff.changed, ...diff.added]
if (incoming.length) {
    writeLiveFiles(root, live.files, incoming)
    stop(
        `These were changed in the Shopify customizer since the last sync:\n${indent(incoming)}\n` +
        '          The live versions are now in your working copy. Review them with "git diff",\n' +
        '          merge them with your own edits, commit, then push again.',
    )
}
for (const path of diff.deletedLocally) info(`${path} was deleted here; this push removes it from live`)
ok('No unsynced customizer changes on live')

// 4. Build
info('Building CSS and JS...')
if (run('npx', ['gulp', 'build'], { cwd: root, live: true }).code !== 0) stop('The build failed. See the errors above.')
ok('Build finished')

if (dryRun) {
    ok('Dry run: every check passed. Nothing was pushed.')
    process.exit(0)
}

// 5. GitHub first, so a rejected push stops us before live changes
const ahead = countCommits(root, '@{u}..HEAD')
if (ahead > 0) {
    if (git(root, 'push', '-q').code !== 0) stop('GitHub rejected the push (someone pushed a moment ago). Run npm run dev, then push again.')
    ok(`Sent ${ahead} commit(s) to GitHub`)
}

// 6. Live theme
info('Uploading the theme to the live store...')
const upload = run('shopify', ['theme', 'push', '--live', '--allow-live', '--no-color', ...shopifyArgs('push', env)], { cwd: root, live: true })
if (upload.code !== 0) {
    fail('The theme upload failed. The code is on GitHub, but the live site may be partly updated. Run npm run push again.')
    process.exit(1)
}
ok('Live theme updated')

// 7. Shopify reformats JSON on upload. Save its version so the next push does
// not mistake the formatting for customizer edits.
const after = pullLiveJson(env)
if (!after.ok) {
    warn('Could not re-read the live theme. If the next push stops on customizer changes, they are probably only formatting.')
} else {
    const d = compareLive({ live: after.files, local: readThemeJson(root), dirty: new Set(), wasDeleted: (path) => wasDeleted(root, path) })
    const normalized = [...d.changed, ...d.added]
    if (normalized.length) {
        writeLiveFiles(root, after.files, normalized)
        if (commitPaths(root, normalized, 'sync: normalize after push').code !== 0 || git(root, 'push', '-q').code !== 0) {
            warn('Saved Shopify formatting locally but could not send it to GitHub. Run npm run dev to retry.')
        }
    }
}

console.log('\n Done. Live at https://theshoemuseum.com\n')
```
